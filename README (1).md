# Ilma Rais — Portfolio

A modern, fully responsive personal portfolio website with a futuristic dark theme, animated particle background, and smooth scroll-triggered interactions.

🔗 **Live site:** https://ilmarais008.github.io/portfolio/

## About

I'm a Computer Science Engineering graduate (Jamia Hamdard, New Delhi) building full-stack products with a focus on AI/ML and data analytics. This site showcases my projects, skills, and experience.

## Features

- Custom animated cursor (dot + trailing ring)
- Canvas-based particle network background in the hero section
- Typing animation for the role title
- Scroll progress bar
- Horizontal auto-scrolling skills marquee
- Bento-grid project layout with hover glow effects
- Scroll-triggered fade/slide reveal animations
- Fully responsive, mobile-first layout
- Respects `prefers-reduced-motion` for accessibility

## Tech Stack

- HTML5, CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (Canvas API, Intersection Observer)
- No frameworks, no build tools — runs directly in the browser

## Project Structure

```
portfolio/
├── index.html      # Page markup
├── style.css        # All styling
├── script.js         # Cursor, particles, typing effect, marquee, scroll reveals
├── resume.pdf         # Downloadable resume
└── README.md
```

## Run Locally

No installation or build step required.

```bash
git clone https://github.com/ilmarais008/portfolio.git
cd portfolio
```

Then just open `index.html` in your browser.

## Deployment

Hosted on GitHub Pages, deployed from the `main` branch.
